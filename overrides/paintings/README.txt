Thank you for downloading JSON Paintings!

The "paintings" folder is where you can define custom paintings, or add painting packs!
See https://github.com/jbredwards/JSON-Paintings-Mod/blob/1.12.2/README.md for more info.

If you add paintings while the game is loaded, run the "/jsonpaintings reload" command.
If you add painting packs while the game is loaded, run the "/jsonpaintings reload"
command then press F3 + T to load their internal resource packs.

Once you're done with this README.txt file, it can be deleted.
